# Матрица ответственности RACI

## Обозначения RACI
- **R (Responsible)** — непосредственно выполняет задачу.
- **A (Accountable)** — несёт ответственность за конечный результат.
- **C (Consulted)** — консультирует исполнителей.
- **I (Informed)** — информируется о ходе или результате.

## 1. Матрица RACI для этапов разработки проекта (СР №1)

| Задачи проекта | Руководитель | Архитектор ПО | Программист | Специалист по данным | Тестировщик |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 1. Определение требований к сервису | A/R | C | C | C | C |
| 2. Проектирование архитектуры сервиса | A | R | C | C | I |
| 3. Формирование базы данных подарков | A | C | I | R | C |
| 4. Разработка интерфейса и функциональности | A | C | R | C | I |
| 5. Разработка алгоритма подбора подарков | A | C | R | R | C |
| 6. Тестирование сервиса | A | C | R | C | R |
| 7. Исправление выявленных ошибок | A | C | R | C | C |
| 8. Подготовка итоговой документации и отчёта | A | R | R | R | R |

## 2. Матрица RACI для работы с Git-репозиторием (СР №2)

| Задачи по работе с репозиторием | Руководитель | Архитектор ПО | Программист | Специалист по данным | Тестировщик |
| :--- | :---: | :---: | :---: | :---: | :---: |
| 1. Создание и настройка репозитория | A/R | C | I | I | I |
| 2. Поддержание структуры папок и файлов | A | R | R | R | R |
| 3. Написание отчётов по практическим работам | A | R | R | R | R |
| 4. Внесение коммитов с осмысленными сообщениями | A | R | R | R | R |
| 5. Проверка пул-реквестов (Pull Request) | A/R | R | C | C | C |
| 6. Слияние веток (Merge) | A/R | C | I | I | I |
| 7. Резервное копирование и поддержание актуальности | A | R | R | R | R |
