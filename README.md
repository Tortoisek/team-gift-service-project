# team-gift-service-project
## Сервис подбора подарков
Командный проект по дисциплине "Введение в профессиональную деятельность".
## Цель проекта
Разработка сервиса, который помогает пользователю подобрать подходящий подарок с учётом интересов, возраста, бюджета, повода и других характеристик получателя.
